# RecipeGenerator

![Swift](https://img.shields.io/badge/Swift-6.0-orange.svg)
![Platform](https://img.shields.io/badge/Platform-iOS%2018+-blue.svg)
![SwiftUI](https://img.shields.io/badge/UI-SwiftUI-purple.svg)

A SwiftUI iOS app that generates personalized recipes using Apple's on-device AI (FoundationModels).

## Features

- AI-powered recipe generation from ingredients
- Detailed nutritional information
- Animated UI with state transitions
- Privacy-first: all processing on-device

## Requirements

- iPhone 15 Pro or newer (A17 Pro chip)
- iOS 18.0+
- Apple Intelligence enabled

## Getting Started

1. Open `RecipeGenerator.xcodeproj` in Xcode
2. Select a compatible device
3. Build and run (Cmd+R)
